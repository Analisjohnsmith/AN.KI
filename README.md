**AN.Ki** is an  operating environment that provides a unified computational layer between the user, applications, services, hardware, and underlying operating system.

AN.Ki may initially operate as an application on an existing operating system.

Applications, files, devices, services, and system functions should appear within one coherent environment.

* It launches.
* It owns the primary user session.
* It manages application access.
* It can be exited or restarted.
* It can be updated independently.
* It can run inside another OS.

### 3.3 OS Independence

AN.Ki should minimize direct dependencies on a particular Linux distribution.

### 3.4 Modular Architecture

Each major subsystem should have a defined interface.

### 3.5 Replaceable UI

The graphical interface must not be inseparable from the Runtime.

### 3.6 Open Implementation

AN.Ki should be capable of being implemented entirely with open-source components.

# AN.Ki

## Application-Shaped Operating System

### Hardware-Integrated System Architecture Specification

**Version:** 1.0
**Status:** Foundational Technical Specification
**System Type:** General-purpose operating environment / operating system
**Primary Architecture:** Application-shaped system with kernel-level infrastructure
**Initial Target:** Linux
**Long-Term Target:** Dedicated AN.Ki system

---

# 1. Abstract

**AN.Ki is an application-shaped operating system architecture.**

The defining characteristic of AN.Ki is that the entire user-facing computing environment is presented as a unified application-like system while retaining access to the full capabilities of the underlying operating system, kernel, drivers, and hardware.

AN.Ki is therefore neither:

* merely a desktop application,
* merely a desktop environment,
* merely a launcher,
* nor merely a Linux distribution.

It is a **unified operating environment** designed to operate across the boundary between application and operating system.

The initial implementation can run on an existing Linux system.

The final implementation can boot directly into AN.Ki.

---

# 2. Fundamental Model

A conventional computer exposes multiple layers to the user:

```text
Hardware
   ↓
Kernel
   ↓
Operating System
   ↓
Desktop
   ↓
Applications
```

AN.Ki changes the user-facing architecture:

```text
Hardware
   ↓
Linux Kernel + Drivers
   ↓
AN.Ki Runtime
   ↓
AN.Ki
```

The user primarily experiences **AN.Ki**.

The kernel remains responsible for privileged operations.

---

# 3. Core Principle

> **AN.Ki makes the operating environment behave like an application without reducing the application to the limitations of ordinary application software.**

AN.Ki therefore has two characteristics simultaneously:

### Application characteristic

It has:

* A unified interface
* A defined runtime
* A lifecycle
* A session
* A user environment
* Application-like modularity

### Operating-system characteristic

It has:

* Hardware integration
* Device management
* Process management
* Filesystem access
* Networking
* Power management
* Security
* System services
* Boot integration
